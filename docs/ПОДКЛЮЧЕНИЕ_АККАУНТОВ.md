# Как подключить Яндекс.Диск и Google Диск

Чужие **публичные ссылки** открываются без всяких ключей: вставили ссылку —
смотрите и скачивайте. Ключи нужны только для того, чтобы видеть **свой**
«Мой диск».

Подключение делается **один раз** и занимает 10–15 минут на каждое облако.
Ключи — это «пропуск» программы в облако: Яндекс и Google выдают его
бесплатно на ваш аккаунт.

Что понадобится в итоге:

| Облако | Что получить | Куда вписать в программе |
|---|---|---|
| Яндекс.Диск | **Client ID** и **Client Secret** | Настройки → «Доступ к облакам» |
| Google Диск | **Client ID** и **Client Secret** (+ по желанию **API Key**) | Настройки → «Доступ к облакам» |

> Если ключи вам уже дал администратор студии — сразу переходите к разделу
> [«3. Вписать ключи и войти»](#3-вписать-ключи-и-войти).

---

## 1. Яндекс.Диск

### Шаг 1. Откройте страницу создания приложения

1. Откройте в браузере **<https://oauth.yandex.ru/client/new>**
2. Войдите в свой аккаунт Яндекса (тот, на котором лежит ваш Диск, или
   рабочий — без разницы, ключи подойдут для входа под любым аккаунтом).

### Шаг 2. Создайте приложение

1. Если Яндекс спрашивает, **для чего** приложение, выберите вариант
   **«Для доступа к API или отладки»**.
2. Заполните поля:
   * **Название сервиса** — например, `НоуКо Cloud` (любое, его видите только вы);
   * **Почта для связи** — ваш настоящий e-mail.
3. В разделе **«Доступ к данным»** (или «Права доступа») найдите
   **«Яндекс.Диск REST API»** и отметьте
   **«Чтение всего Диска»** (технически это `cloud_api:disk.read`).
   Запись и удаление программе не нужны — не отмечайте их.
4. Если есть поле **Redirect URI** — впишите
   `https://oauth.yandex.ru/verification_code`
   (у типа «Для доступа к API» оно обычно уже заполнено само).
5. Нажмите **«Создать приложение»**.

### Шаг 3. Скопируйте ключи

На странице созданного приложения (её всегда можно найти на
**<https://oauth.yandex.ru>** → «Мои приложения») есть два значения:

* **ClientID** — длинная строка из букв и цифр → это **Client ID**;
* **Client secret** — вторая строка (иногда скрыта, нажмите «Показать») →
  это **Client Secret**.

Скопируйте оба — они понадобятся в разделе 3.

> **Никому не показывайте Client Secret.** Если он «утёк» — на странице
> приложения нажмите «Сбросить секрет» и впишите в программу новый.

## 2. Google Диск

У Google настройка длиннее, но делается тоже один раз.

### Шаг 1. Создайте проект

1. Откройте **<https://console.cloud.google.com>** и войдите в Google-аккаунт.
2. Вверху слева нажмите на выбор проекта → **«New project» (Создать проект)**.
3. Название — например, `NoukoCloud` → **Create**. Подождите несколько
   секунд и убедитесь, что вверху выбран именно этот проект.

### Шаг 2. Включите Google Drive API

1. Откройте **<https://console.cloud.google.com/apis/library/drive.googleapis.com>**
2. Нажмите **Enable (Включить)**.

> Без этого шага программа покажет ошибку «В проекте Google Cloud не включён
> Google Drive API». После включения подождите 1–2 минуты.

### Шаг 3. Настройте экран входа

1. Откройте **<https://console.cloud.google.com/auth/overview>**
   (раздел может называться **«Google Auth Platform»** или
   **«OAuth consent screen»** — это одно и то же).
2. Нажмите **Get started (Начать)** и заполните:
   * **App name** — `НоуКо Cloud`;
   * **User support email** — ваша почта;
   * **Audience (Аудитория)** — **External (Внешние)**;
   * **Contact information** — ваша почта.
3. Согласитесь с правилами и нажмите **Create**.
4. Откройте вкладку **Audience (Аудитория)** → раздел **Test users** →
   **Add users** и добавьте **свою почту** и почты всех, кто будет входить
   через программу. Без этого Google не пустит: «Доступ заблокирован».

> Приложение остаётся в режиме **«Testing»** — это нормально для своей
> студии (до 100 тестовых пользователей). Публиковать его не нужно.

### Шаг 4. Создайте ключи (OAuth client)

1. Откройте **<https://console.cloud.google.com/auth/clients>**
   (или **APIs & Services → Credentials → Create credentials → OAuth client ID**).
2. Нажмите **Create client (Создать клиента)**.
3. **Application type (Тип приложения)** — обязательно
   **Desktop app (Приложение для ПК)**. Другие типы не подойдут.
4. Название — любое, например `НоуКо Cloud` → **Create**.
5. Появится окно с ключами:
   * **Client ID** — заканчивается на `.apps.googleusercontent.com`;
   * **Client secret** — начинается с `GOCSPX-`.

   Скопируйте оба сразу. **Client secret Google показывает целиком только
   при создании** — на всякий случай нажмите **Download JSON** и сохраните
   файл: в нём есть оба значения.

### Шаг 5 (необязательно). API-ключ для публичных папок Google

Нужен, только если вы открываете **чужие публичные папки Google Диска без
входа** в аккаунт.

1. Откройте **<https://console.cloud.google.com/apis/credentials>**
2. **Create credentials → API key**.
3. Нажмите **Edit API key** → в «API restrictions» выберите
   **Restrict key → Google Drive API** → **Save**.
4. Скопируйте ключ (начинается с `AIza`) — это **API Key**.

## 3. Вписать ключи и войти

1. Откройте НоуКо Cloud → **«Настройки»** (вверху справа).
2. В блоке **«Доступ к облакам»** вставьте:
   * Яндекс.Диск — **Client ID** и **Client Secret**;
   * Google Диск — **Client ID**, **Client Secret** и (если делали) **API Key**.
3. Нажмите **«Сохранить»**.
4. Откройте **«Аккаунты»**.

### Вход в Яндекс

1. Нажмите **«Войти через Яндекс.Диск»** — откроется браузер.
2. Войдите в Яндекс и нажмите **«Разрешить»**.
3. Яндекс покажет **код подтверждения** (буквы и цифры). Нажмите
   «Скопировать» рядом с ним.
4. Вернитесь в программу — код подставится сам. Нажмите **Enter**.
   Код живёт 10 минут: если не успели — нажмите «Войти» ещё раз.

### Вход в Google

1. Нажмите **«Войти через Google Диск»** — откроется браузер.
2. Выберите аккаунт (тот, что добавлен в **Test users**).
3. Google предупредит **«Google hasn't verified this app» (приложение не
   проверено)** — это нормально для своего приложения в режиме Testing.
   Нажмите **«Advanced» (Дополнительно)** → **«Go to НоуКо Cloud (unsafe)»
   (Перейти)**.
4. На странице разрешений **обязательно отметьте галочку
   «See and download all your Google Drive files»** (Просмотр и скачивание
   всех файлов на Google Диске) и нажмите **Continue**.
5. Браузер напишет «Готово» — возвращайтесь в программу.

После входа «Мой диск» появится в левой колонке сам.

## 4. Если что-то не получилось

| Что видите | Почему | Что сделать |
|---|---|---|
| Яндекс: «Код введён неверно» | Скопировано не то (ссылка, старый код) | Скопируйте именно код со страницы Яндекса |
| Яндекс: «Код не подошёл: он мог истечь» | Прошло больше 10 минут | Нажмите «Войти через Яндекс.Диск» заново |
| Яндекс: «У приложения нет прав на Яндекс.Диск» | Не отмечено «Чтение всего Диска» | oauth.yandex.ru → ваше приложение → «Редактировать» → отметьте право → войдите заново |
| «Ключи приложения неверны» | Опечатка или лишний пробел в ключе | Скопируйте ключ ещё раз целиком |
| Google: «Доступ заблокирован» / 403 access_denied | Вашей почты нет в Test users | Шаг 3 Google, пункт 4 |
| Google: «Нет доступа к Диску» | Не отмечена галочка про Google Диск при входе | «Аккаунты» → войдите заново и отметьте галочку |
| Google: «Не включён Google Drive API» | Пропущен шаг 2 | Включите Drive API и подождите 1–2 минуты |
| Google: redirect_uri_mismatch | Тип клиента не «Desktop app» | Создайте новый клиент типа **Desktop app** |
| Публичная папка Google не открывается без входа | Нет API Key | Шаг 5 Google или просто войдите в аккаунт |

Подробности любой ошибки — кнопка **«Журнал»** внизу окна программы
(файл `errors.log`).

### Как отозвать доступ программы

* Яндекс: **<https://id.yandex.ru/personal/data-access>**
* Google: **<https://myaccount.google.com/connections>**
